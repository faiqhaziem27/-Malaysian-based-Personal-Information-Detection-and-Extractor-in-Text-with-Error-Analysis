# Extended Malaysian NER Dataset Guide

## 1. Overview

`data/malaysia/malaysia_ner_extended.json` adds 100 synthetic Malaysian sentences on top of the original 100 in `malaysia_ner_samples.json`. It uses the same format and the same 7 BIO labels (`O`, `B-PER`, `I-PER`, `B-ORG`, `I-ORG`, `B-LOC`, `I-LOC`), so the existing preparation and tokenization scripts work with it.

The file is generated by `src/generate_malaysia_ner_extended.py` (seed 2026), so it can be rebuilt exactly:

```bash
python src/generate_malaysia_ner_extended.py
```

## 2. How it differs from the original dataset

| | Original (`malaysia_ner_samples.json`) | Extended (`malaysia_ner_extended.json`) |
|---|---|---|
| Size | 100 | 100 |
| Language | English | English, Malay, Manglish |
| Entity mentions | 97 PER, 88 ORG, 92 LOC | 70 PER, 80 ORG, 42 LOC |
| Sentence styles | Incident reports, support chat | Chat messages, emails, form fields (`Name : ... \| Bank : ...`), news-style, two-person sentences, location-only and person-only sentences |
| Organisations | 63 | 47 (none shared with the original), including abbreviations such as UTHM, BSN, JPJ |
| Locations | 43 | 30 (none shared with the original) |
| Person names | 97 | 68 unique (no full name shared with the original), with Malay, Chinese, Indian, Sikh and Sabah/Sarawak naming patterns |
| Test templates | n/a | Held out: validation/test sentence templates never appear in training |

## 3. Splits

| Split | Samples | Negatives (all `O`) |
|---|---:|---:|
| Train | 70 | 9 |
| Validation | 15 | 1 |
| Test | 15 | 3 |

Training split label counts: see the output of `python src/load_malaysia_dataset.py` after preparing.

## 4. Annotation conventions

Same as the original dataset:
- Professional titles (`Dr.`, `Prof.`, `Ir.`, `Ts.`, `Encik`, `Puan`, `Cik`) are tagged `O`.
- Malaysian honorifics (`Dato'`, `Datin`) are part of the person span (`B-PER`), the same as `Dato' Sri` and `Datuk` in the original file.
- Titles match the person's gender where it is clear.
- Companies are only used in templates that fit them (for example, only banks appear after `Bank :`).
- `bin`, `binti`, `a/l`, `a/p` and `anak` are part of the person span (`I-PER`).
- Prefixes such as `Wan`, `Nik`, `Syed`, `Tengku` are part of the person span.
- Punctuation is a separate token tagged `O`.

## 5. Using it

Point `MALAYSIA_RAW_DATA_PATH` in `src/project_paths.py` at the new file, then run the usual scripts:

```bash
python src/prepare_malaysia_dataset.py
python src/load_malaysia_dataset.py
```

To train on both files, merge the `train` lists and keep the original 15 test sentences as an extra hand-written test set.

## 6. Limitations

- All sentences are synthetic and template-based, so scores on this test set will be higher than on real text.
- Evaluate on real or hand-written sentences as well (for example the original test split).
